# Пользовательская документация GlowAi (MVP)

## Что это
GlowAi помогает путешественнику за несколько минут получить план ухода за кожей с учётом климата поездки и ваших симптомов.

## Как пользоваться
1. Укажите город дома и город поездки.
2. Выберите режим «До поездки» или «SOS на месте».
3. Заполните тип кожи и симптомы (по желанию добавьте фото лица).
4. Нажмите «Получить план» — увидите климат-риски, шаги ухода и packing-list.

## Важно юридически
- GlowAi **не является медицинским сервисом** и не ставит диагноз.
- Фото лица обрабатываются для формирования рекомендаций; в MVP хранение минимизировано (запрос обрабатывается в памяти/через LLM API).
- При серьёзных симптомах (ожог, инфекция, сильная боль, аллергия) обратитесь к врачу.
- Перед продакшеном: политика ПДн (152-ФЗ), согласие на обработку биометрии/изображения, оферта.

## Ограничения MVP
- База локальных SKU и карта аптек ещё не подключены.
- Без LLM-ключа работает rule-based fallback.
- Follow-up push пока подсказка текстом, не уведомление.
