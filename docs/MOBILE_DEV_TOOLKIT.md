# Mobile Dev Toolkit в GlowAi

Подключено из: https://github.com/TMHSDigital/Mobile-App-Developer-Tools

## Что взяли
- **17 skills** (все Flutter + ключевые shared: AI, API, camera, permissions, testing, security, theming, …)
- **10 rules** (+ проектный `glowai-project.mdc`)
- **MCP** `@tmhs/mobile-mcp` через `.cursor/mcp.json`

## Что не копировали целиком
Expo/React Native skills (у GlowAi стек Flutter). При необходимости — в `_refs/Mobile-App-Developer-Tools/skills/`.

## Как пользоваться в Cursor
1. Перезапустите Cursor / обновите MCP.
2. В чате формулируйте задачу естественно — агент подхватит skill по description.
3. Примеры:
   - «телефон не видит flutter devices»
   - «добавь экран follow-up по паттерну навигации»
   - «проверь секреты и cleartext перед пилотом»
