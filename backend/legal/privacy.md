# GlowAi — политика обработки данных (пилот)

GlowAi **не является медицинским сервисом** и не ставит диагноз.

## Какие данные собираем

- Email, имя, хеш пароля (для аккаунта)
- Анкета (тип кожи, симптомы), маршрут и даты поездки
- Результаты анализа (текстовый план, климат, packing-list)
- Сообщения чата follow-up по проверке
- Опциональное селфи: **в памяти запроса analyze**, на диск и в БД GlowAi **не пишется**

## Селфи и нейросеть

Если вы дали согласие и на сервере включён LLM с vision:

1. Фото один раз передаётся на backend
2. Backend может отправить изображение во **внешнего LLM-провайдера** (OpenAI-compatible API, например Gemini) только для построения плана
3. GlowAi не архивирует фото после ответа

Без согласия селфи не отправляется. Без LLM используется rule-based план без vision.

## Согласия

- При регистрации: условия использования и эта политика
- Перед селфи: отдельный чекбокс в UI

## Климат

Для `pre_trip` с датами: прогноз Open-Meteo на окно поездки (если в горизонте ~16 дней) или сезонный архивный ориентир. Для `SOS` — актуальная погода. В ответе есть поле `window` / подпись в UI.

## Follow-up

Напоминание через ~48 ч: in-app список «Пора оценить» и (если настроен SMTP) письмо фоновым воркером.

## Хранение и удаление

- Проверки и чат — в серверной БД аккаунта
- `DELETE /api/v1/auth/me` удаляет аккаунт и связанные данные
- Фото лица не храним

## Пилот / 152-ФЗ

Минимизация данных, дисклеймер «не медуслуга». Перед публичным релизом — полная оферта и юр.проверка.
